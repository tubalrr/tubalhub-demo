### Real-data architecture

The project is designed around real connected data. Empty states remain empty rather than inventing activity. Demo/catalog content is explicitly labeled where included.

### Security architecture

Protected operations are handled through Firebase rules and trusted Cloud Functions. Paid digital-download access is authorized server-side. The package does not include the seller's private credentials, service-account keys, or Firebase Admin secrets.

- Their own payment provider, when needed
